常见问题

连接失败，先检查什么？

检查服务地址、接口类型、模型 ID、Key 权限与额度；内网服务还需要公司网络或 VPN。如果本地服务离线，在客户端打开“管理后台服务”，按检查结果启动或修复；脚本版可重新运行安装入口。验证失败不会替换原连接。

可以保存多个服务吗？

目前一次启用一个服务与模型。服务列表是连接预设；切换时重新填写对应 Key 并验证，再在 Claude 更新 Key、导入配置并重启。

支持 Claude Design 和 Cowork 吗？

这些功能尚未验证，第三方 Key 不会解锁官方账号权益。当前开源版的真实供应商与 Code 完整任务验收仍待补齐。图片、附件、长上下文和其他服务的兼容性需分别验证。

如何停用或卸载？

系统设置的“登录项与扩展”中，后台项名称为“ModelBridge 模型连接服务”，使用期间请保持开启。停用前先在 Claude 切换到其他可用配置，在本页点击“停用后台服务”；脚本版可运行“卸载 ModelBridge.command”。停用会停止后台服务并取消自动启动，保留本地配置供恢复。关闭此窗口不会停止服务。
