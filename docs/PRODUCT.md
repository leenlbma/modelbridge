# 产品范围

ModelBridge 面向已有 API Key、希望在 Claude 桌面端 Code 使用其他模型的用户。通用表示支持多个服务和接口，不表示所有平台、客户端和模型已通过验证。

## 当前范围

- macOS 14+ Apple Silicon Electron 客户端与本机 Python 网关。
- 五类服务入口：OpenAI、Anthropic、DeepSeek、OpenRouter、自定义。
- Responses、Chat Completions、Messages；一次启用一个连接。
- 验证后保存、流式结构检查、取消与超时、失败保留当前配置。
- 原生菜单、菜单栏、导出、环境检测、安装恢复、停用和依赖缓存复用。
- 本机访问控制、独立管理令牌、指纹校验、不含 Key 的配置导出。

## 体验约定

已保存连接与未验证草稿分开；切页保留草稿，导出绑定已保存配置。验证时锁定重复操作，成功后清空输入 Key。后台离线时显示上次状态并禁用提交。只有真实请求完成才显示连接成功。

默认服务为 OpenAI，模型由用户明确选择；不内置私人网关或公司模型。早期没有服务地址的配置不会被猜测或自动指向另一个供应商。

## 尚未承诺

多连接收藏、系统钥匙串、自动更新、自动故障切换、Windows/Intel 客户端、Claude Design/Cowork 和所有模型完整兼容均不属于当前已交付能力。

## 优先顺序

1. 公共供应商真实网关与 Code 任务验收，按版本记录结果。
2. 全新 Mac、重新登录、网络故障恢复与签名公证。
3. 多连接、系统凭据管理、故障自助。
4. 独立验证 Claude Code CLI 与其他入口，再讨论跨平台。

评估接入成功率、首次成功耗时和工具调用完成率；当前产品没有遥测采集系统，不应为获取指标上传用户提示词或代码。
